# 결혼준비해요 (`wedding-check`) — gh-pages

토스 미니앱 「결혼준비해요」의 **로고와 개인정보 처리방침**만 두는 저장소다. 앱 코드는 여기 없다(`shoo99/toss-benefit-wed`, private).

| 파일 | 쓰이는 곳 |
|---|---|
| `logo-600.png` | `app/granite.config.ts` 의 `brand.icon` · **콘솔 앱로고와 같은 파일이어야 한다**(다르면 반려) |
| `privacy.html` | 콘솔 「개인정보 처리방침 URL」 |

🔴 이 저장소가 **public** 인 이유: private 은 GitHub Pages 가 유료 플랜에서만 나온다.
🔴 로고 URL 이 404 면 심사에서 반려된다(심리앱 실제 사유). 바꾼 뒤엔 URL 로 실측할 것.
